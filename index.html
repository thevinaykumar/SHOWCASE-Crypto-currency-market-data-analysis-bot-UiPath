System Architecture
Automated Workflow Pipeline

A precisely orchestrated seven-stage operational pipeline — from raw market data access to intelligent reporting delivery.

01

Market Website Access

UiPath Browser Automation navigates to CoinMarketCap, establishing a live connection to real-time cryptocurrency market data.

Browser Automation · UiPath
02

Live Bitcoin Price Extraction

Get Text activity selects the live Bitcoin price element, capturing the raw price string directly from the DOM.

Get Text · DOM Extraction
03

OCR / Image Processing

Computer Vision and UiPath OCR modules process price screenshots, converting visual data into structured text strings.

Computer Vision · OCR Processing
04

Structured Data Conversion

CDbl() conversion and string replacement operations transform raw price text into clean, comparable numeric values.

Data Transformation · VB.NET
05

Threshold Logic Evaluation

Conditional If/Else logic compares current price against configurable buy/sell thresholds, determining action signal.

Conditional Logic · Decision Engine
06

Buy / Sell Decision Workflow

Action assignment and Message Box alert generation notifies operators of triggered buy or sell conditions in real-time.

Signal Generation · Alert Dispatch
07

Automated Reporting & Notifications

Write Range Workbook writes timestamped records to CryptoData.xlsx; Send SMTP Email dispatches Crypto Alert to registered recipients.

Excel Logging · SMTP Notification
